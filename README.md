# RocketLeague X360

Original 3D car football game for Xbox 360.

## Platform
- Xbox 360 RGH/JTAG
- XSDK
- C17
- GitHub Actions

## Planned features
- 3D arena
- Controllable car
- Ball physics
- Camera system
- Goals and scoreboard
- Xbox 360 controller support

## Build
Compiled through GitHub Actions.
